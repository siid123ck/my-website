# Nepal Trekking Starter Guide

A single-page guide for travelers planning their first trek in Nepal. It covers how to choose a route, permits and TIMS cards, guides and porters, seasons, altitude safety, packing, teahouses, and budgeting.

## Features

- **Topic cards:** eight cards that expand to show full instructions.
- **Route list by season:** a season picker that highlights the routes suited to your travel dates.
- **Packing checklist:** tick items off as you pack, with a running count.
- **Budget estimator:** enter your trekking days and comfort level for an approximate total.
- **Back-to-top button:** appears after scrolling past the hero section.

## Files

- `index.html`: page structure and content
- `styles.css`: colors, fonts, layout, and hover styles
- `script.js`: interactive features
- `images/`: photos used on the page (add `hero.jpg` here)
- `README.md`: this file

## Setup

1. Clone or download this repository.
2. Add a mountain photo named `hero.jpg` to the `images/` folder. Without it, the hero shows a green-to-blue gradient.
3. Open `index.html` in a web browser. No build step or installation is needed.

## Notes

- Permit fees, costs, and seasons change. Check current information with official sources before you travel.
- Budget figures are approximate and exclude permits, flights, and guides.
- Use royalty-free photos and credit the photographers in the footer.
